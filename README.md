# HackTrainer

A standalone Godot 4 practice game for learning node-based exploration hacking mechanics inspired by EVE-style relic/data site hacking.

## Current prototype

- Procedurally generated connected hacking board
- Virus Strength and Coherence
- Defensive nodes
- Utility nodes
- Hidden System Core
- Easy / Standard / Hard modes
- Optional Training Mode hints

## Planned

The next iteration will make the trainer substantially closer to the real hacking puzzle:

- 1–5 distance clues on explored empty nodes
- Proper hex-style topology
- Rule of Six behaviour
- Core placement constraints / Rule of 8
- Data caches
- More authentic defensive and utility subsystem types
- Better training explanations and strategy feedback

## Run

Requires Godot 4.

Open `project.godot` in Godot and press F6/F5.

## Note

This project uses original code and presentation. It is intended as a practice trainer for the gameplay concepts and does not include CCP artwork or game assets.
